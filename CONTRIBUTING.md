# Contributing to fishpylib
Controbutions to fishpylib are welcome.
The project aims to provide accessible, reproductive and scientifically grounded computational tools for fisheries science.

## How to contribute
Contributions may include:
- Development of scientific methods and computional tools;
- Bug reports and corrections;
- Improvements to documentation;
- Scientific references and methodological suggestions;
- Tests and validation procedures;
- Examples and educational materials.

## Development guidelines
Contributions **SHOULD** follow these principles:
1. Scientific methods must be supported by appropriate references;
2. New funcionality should include automated tests;
3. Public functions and classes should have clear documentation;
4. Code should follow established Python conventions;
5. Changes should preserve reproducibility and numerical consistency;
6. Existing functionality should not be modified without appropriate justification.

## Reporting issues
Before reporting an issue, check whether it has already been reported.
When submitting an issue, provide a clear description of the problem, the expected behavior and, whenever possible, a minimal reproductible example.

## Pull requests
Pull requests should:
- Have a clear and descriptive title;
- Explain the purpouse of proposed changes;
- Include tests for new functionality;
- Update the documentation when necessary;
- Reference relevant scientific literature when applicable.

## Scientific integrity
The *fishpylib* project values scientific accuracy and transparency.
Methods should not be presented as scientifically validated without appropriate theoretical support, testing and methodological justification.
